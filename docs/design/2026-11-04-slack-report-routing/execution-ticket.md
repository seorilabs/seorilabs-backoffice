검증은 최종 후보 SHA를 커밋한 다음 실행한다. 전체 테스트, 타입·lint, 웹·worker 빌드에 더해 격리 DB에서 822개 순위 관측과 중단·재개, GA4 수집·저장부터 분석·발송까지, 수동 앱인토스 입력, 기존 대기 신호 보존, AI 실패, 중복 요청, 정정 중 경합을 실행한다. 외부 수집 경계와 AI·Slack 호출은 격리 응답으로 대체하고 실제 DB와 worker를 사용한다. 운영 수신은 배포 후 별도 확인한다.

수신 확인에서는 현재 순위 회차 1건을 복구하고, GA4 수집과 앱인토스 수집을 각 1회 실행한다. KDP는 실제 저장 자료를 사용한 경로 확인 메시지를 검증용으로 표시한다. 신규 판매를 꾸미거나 과거 여러 회차를 재발송하지 않는다. 각 원장·분석·발송 ID와 Slack 링크를 대조한다.

원본 로그와 테스트 산출물은 저장소 밖에 보관하고 NAS1dual에 복사·해시 대조한다. Git에는 요약과 NAS 위치를 남긴다. 계획 미실행과 provider 전송 결과 불명을 통과로 기록하지 않는다.
