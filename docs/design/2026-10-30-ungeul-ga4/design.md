# 운글 GA4 중앙 연결 복구

2026-10-30 사용자의 운글 지표 수집과 계측 수정 계획을 구현과 운영 반영 승인 근거로 한다.

선택적인 설정 payload.ga4를 enabled, projectId, datasetId로 정의한다. ACTIVE 설정의 연결을 기존 App 필드와 fallback보다 우선하며 false이면 제외한다. 항목이 없으면 기존 동작을 유지한다. 기존 공통 해석기에 연결하고 수집, 보고, 실시간, 상태 조회에서 ACTIVE revision을 함께 읽는다. DB 스키마와 기존 앱 설정을 변경하지 않는다.

재수집의 선택적 appId는 대상 확인 후 운글만 처리한다. 잘못된 대상은 BigQuery 호출과 원장 생성 전에 거절한다. 설정 생성과 활성화는 기존 API를 사용해 동시 변경, 중복 요청과 감사 기록을 유지한다. 운영은 현재 설정 전체를 보존한 새 revision으로 변경하며 실패 시 기존 revision을 정상 API로 되살린다.

L1 개발 환경에서 활성 선택, 비활성 제외, fallback 유지, 설정 검증과 기존 동시 변경 및 중복 요청 회귀, 대상 한정 수집을 확인한다. 필수 타입, lint, build 검사를 실행한다. 운영 배포 후 공용 수집 identity의 운글 데이터셋 조회, 37일 수집 및 저장 지표와 원장을 대조한다. 기기는 사용하지 않는다.
