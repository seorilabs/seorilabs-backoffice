# Slack 전체 이전 실행

이슈: [#548](https://github.com/seorilabs/seorilabs-backoffice/issues/548)

사용자가 승인한 설계 `585279e`와 “승인한다. 모두 이전해라.”라는 확대 지시를 [설계 v2](design.md)에 반영했다. [테스트 계획](test-plan.json)의 L3 개발 환경 검증, PR, 운영 서비스 전환과 실제 수신 확인까지 수행한다.

구현은 새 Slack 수신부와 전송 경계, 기존 운영 서비스 이동, 추가 DB schema와 요청 영수증, 13개 목적지와 기존 21개 기능, 권한과 확인, 보존 정리, 명시적인 대기 작업 이관을 포함한다. 이번 변경은 프로토콜과 생산자, DB와 소비자가 함께 전환되어야 하므로 한 후보로 묶었다. 파일 이동은 rename으로 검토한다.

실제 계정과 앱, 봇 권한 7개, 13개 채널과 봇 및 운영자 참여를 확인했다. 개인피드만 비공개다. 운영 초기 조회에서는 Discord 미발송과 실행 중 명령은 0건, 열린 장애 2건, 대기 승인 0건이었다. 이 값은 전환 직전에 다시 조회한다. 아직 운영 배포와 자연 수신은 완료하지 않았다.

독립 검수에서 발견한 승인 종류별 권한, 단계 초안의 권한 회수, 삭제된 첨부 카드 재발행, Slack 조회의 form encoding, 부분 성공 게시물 보존 정리를 수정하고 실패 회귀를 추가했다. 최종 후보의 전체 실행과 중앙 검증, 배포 readback은 별도 근거에 결합한다. 테스트 원문, 로그와 화면은 작업 종료 시 NAS1dual에 복사와 해시 대조 후 보관한다.
