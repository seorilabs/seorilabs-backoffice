# 1차 마켓 검색 문구 변경안 v1

상태: 사람 승인 전 제안. 마켓과 중앙 설정에는 아직 저장하지 않았다. 이 문서는 운영 설정 정본이 아니다. 승인 후 Backoffice의 기존 validator와 서비스로 새 설정 버전을 만들고, 공식 마켓에서 저장값을 다시 읽는다.

범위는 아래 5개 앱의 한국어와 기존 영어 등록 정보다. 가로세로 퍼즐은 한국어만 포함한다. 모든 언어의 기존 상세 설명, 홍보 문구, 출시 노트, 이미지, 가격, 국가, 법적 선언, 심사 중 버전과 빌드 연결은 유지한다. 설명 첫 문장과 스크린샷 재제작은 2차 후보이며 이번 저장 대상에서 제외한다.

36개 고유 문안을 작성했으며 제목 9개를 두 마켓에 적용하므로 실제 저장 대조 대상은 45개 필드다. App Store 제목과 부제는 각 30자, 키워드는 100자 이내로 검사했다. Google Play 제목은 같은 이름 후보를 사용하고, 80자 짧은 설명은 아래 별도 문안을 쓴다. Google Play에는 숨은 키워드 입력란을 만들지 않는다.

## 검색어 관측 보완안

새 검색어는 기존 관측의 연속성을 위해 추가한다. 기존 검색어와 과거 순위를 지우지 않는다. 아래 값은 마켓 키워드 필드가 아닌 Backoffice의 관측 설정이다.

| 앱 | 추가할 검색어 | 이유 |
| --- | --- | --- |
| lizard-tycoon | 안녕 도마뱀, Hello Lizards | 현재 네이티브 제목으로 추적 보완. 앱인토스의 Lizard Terrarium은 독립 이름으로 유지 |
| spiritgate-defenders | 혼문, Spiritgate Endless Night, 픽셀 디펜스, defense RPG | 현재 네이티브 제목과 실제 장르 보완. 타워 설치를 지원한다고 주장하지 않음 |
| reascend | 리어센드, Reascend, 방치형 RPG, idle tower RPG | 공개 앱의 검색어 설정이 비어 있음 |
| lucid-chess | 체스 힌트, chess hints, chess analysis | 광범위한 chess 외에 실제 후보 수와 복기 기능을 관측 |
| babycare | 공동 육아 기록, shared baby tracker, breastfeeding log | 공동 돌봄과 수유라는 검색 의도를 분리해 관측 |

현재 monitoring 계약은 국가 목록과 검색어 목록의 모든 조합을 조회한다. 이를 국가별 언어 검색량이나 실제 스토어 순위로 해석하지 않는다. 국가별 전용 검색어 모델을 새로 만드는 것은 이번 범위에 없다.
