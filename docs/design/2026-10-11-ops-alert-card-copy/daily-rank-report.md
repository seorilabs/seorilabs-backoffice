변화 없는 행도 포함한다. 검색 결과 밖은 “결과 목록에 없음”, 조회 실패·진행 중·당일 미수집·해당 국가 리스팅 미확인을 구분한다. 전날 자료를 오늘 순위로 표시하지 않는다. 이전 날짜는 실제 마지막 성공 관측 날짜이며 하루 간격이라고 가정하지 않는다. 같은 날짜 재발행은 기존 카드를 갱신하고 멘션은 없다. CSV는 UTF-8 BOM·따옴표 이스케이프·수식 실행 방지와 원본 URL을 포함한다.

기존 NotificationEvent의 OPS_ALERT와 outbox/단일 첨부 경로를 재사용한다. 새 schema·AI 분석·검색 요청·유료 공급자는 없다. 원장은 SourceCollectionRun, MarketObservation, ACTIVE ConfigRevision이다. 당일 앱·조합 전체를 쿼리하며 기존 최신 100건 제한을 적용하지 않는다. 발행 실패는 기존 outbox가 재시도한다. 고정된 KST 날짜를 dedupe key에 사용하고 메시지·첨부는 발행 시점의 같은 조회 결과를 사용한다. 화면 링크는 기준일을 고정하며 현재 추적 설정의 해당일 최신 관측을 보여 주고, 첨부는 발행 시점 기록이라고 표시한다.

검증: 111행 완전성, 날짜 경계·결측·null 순위·첫 관측·실패/빈 리스팅·동일 날짜 중복·CSV 특수문자/수식 방지. 기존 3회 독립 UI 검수에 전체표 소형 화면·큰 글자·오류·빈 상태를 포함한다. 운영 배포·새 정기 실행 활성화는 최종 후보의 별도 배포 승인으로 수행한다. 복구는 이전 이미지와 정기 실행 중지이며 기록은 삭제하지 않는다.
