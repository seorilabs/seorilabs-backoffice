## PR #463 교차 리뷰 후 회귀 수정

- `6faebf0`에서 CI와 최종 전체43개 E2E·빌드를 통과한 뒤 공개 PR 코드를 읽기 전용 Claude로 한 번 교차 리뷰했다. 원문은 PR 댓글에 그대로 보존했다.
