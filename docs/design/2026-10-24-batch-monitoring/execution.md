# 배치모니터링 실행 기록

- 실행 티켓: [#530](https://github.com/seorilabs/seorilabs-backoffice/issues/530).
- 승인: 사용자가 이 대화에서 “승인한다.”고 답했다. 승인 대상은 설계와 테스트 계획의 커밋 `083904c`, L1 개발 환경 검증, PR 병합과 서비스 운영 반영이다.
- 인수조건: 같은 폴더 design.md의 AC-1~AC-8을 그대로 실행한다. 기기 사용과 운영 장애 생성은 없다.
- TDD: 기존 코드에서 미제공만 남은 앱인토스의 성공 표시와 KDP 실행별 전용 채널 보고 테스트가 실제 요구 불충족으로 실패했다. 알림 소비자 선행 배포의 실패와 통과도 별도 확인한다.
- 격리: 전용 로컬 MySQL `backoffice_batch_monitoring_test`, 합성 지표와 시계, Discord HTTP fixture를 사용한다. 실제 운영 데이터와 인증값은 격리 DB에 넣지 않는다.
- 검증 원본: 작업별 외부 산출물 폴더에서 관리하고 최종 후보 SHA, 결과와 해시를 NAS 검증 목록에 보존한다. 실행 전 설계 문서나 예제 수치를 통과 결과로 사용하지 않는다.
- 운영 검증: 배포 후 실제 immutable 이미지, 새 채널 설정과 전송 권한, 수집과 DB 재조회, 대기열의 SENT와 실제 메시지를 대조한다. 자연 장애와 복구는 관측 전까지 미확인이다.
