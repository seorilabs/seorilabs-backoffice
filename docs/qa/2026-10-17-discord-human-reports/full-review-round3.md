# 새 전체 검수 3회와 최종 회귀의 구분

독립 검수자 `/root/review_judgment`가 후보 `a1f9e0b6b081f53972220d7c7018a74a5009f905`에서 핵심 11개 기능과 사용성을 모두 실제 실행·판정했다. 새 전체 검수 3회는 누적 5회이며, 이전 1·2회 결과와 결함 원문을 보존했다. 390px·200%에서 공통 헤더의 실제 좌표와 화면을 읽어 겹침 수정을 확인했다. 빈 날짜의 외부 초점 이탈·복원, 리뷰 가림과 실제 초안 저장, 중요한 비용 단계의 새 메시지, 이전 기호 겹침과 첫 중복 편집도 재확인했다.

원본 `full-review/round3/review-result.json`·`central-review-fragment.json`과 `ui-source-file-hashes.json`에 판정·해결 근거가 있다. 원본 browser 실행의 도구 순서 오류, 서비스의 공유 날짜 fixture 충돌, fresh/legacy 원본 실패는 별도 원문으로 남겼다. 이를 처음부터 전체 통과였다고 바꾸지 않는다.

최종 전체 회귀에서 `test-operations-insights.ts`가 대상 delivery가 아닌 앞선 fallback delivery를 멈춘 뒤 대상의 상태를 확인하는 실행기 결함을 발견했다. 유일한 목적지 키로 대상을 식별하고 그 대상에서만 대기·검사하도록 테스트만 수정했다. 제품 `src/`·schema·worker 진입점은 UI 검수 후보와 동일하다.

이 테스트 수정 뒤 정확한 새 후보 SHA에서 독립 L3 통합 회귀를 다시 실행한다. 실제 웹 재시작·경로/API 경계, 백엔드 계약 44개 기능 매핑, 서비스 25사례, 전체 단위·형·린트, 신규/기존 이력 DB의 원본 migration 계약을 확인한다. UI 검수의 과거 source를 새 SHA로 소급하지 않으며 새 UI 검수 4회로 세지 않는다. 최종 L3·중앙 검증·빌드·CI·운영 적용의 결과는 PR 실행 근거에 별도로 연결한다. 이 문서는 해당 단계의 통과를 미리 선언하지 않는다.
